Website disclaimer

Please read this before you use ULEP.

  • A student project. ULEP is an educational website. It gives you a simple way to explore basic digital image editing and learn how images are processed.
  • Results may vary. Image processing results depend on the original image and the settings you choose. Resizing and compression may affect image quality.
  • Your images. Make sure you have permission to use any image you upload. Avoid uploading private or sensitive images.
  • Not professional software. ULEP is meant for learning. It is not a substitute for professional image-editing software.

Learn about digital images

Discover how digital images work and how you can manage them using ULEP.

Pixels

Pixels are the tiny elements that form a digital image.

Resolution

Resolution refers to the number of pixels in an image.

Image resizing

Resizing changes the width and height of an image.

Image compression

Compression reduces an image's file size to make it easier to store or share.

RGB colors

RGB stands for Red, Green, and Blue, which are combined to create colors.

Image file formats

Learn about common image formats such as JPEG and PNG.

How to use ULEP

  1. Upload an image from your device.
  2. Preview your selected image.
  3. Adjust the image width and height.
  4. Choose the image quality and output format.
  5. Click Process Image.
  6. Download your processed image.
